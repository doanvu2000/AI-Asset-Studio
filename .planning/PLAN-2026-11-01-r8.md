### #59 Combat frame data
- Vào: sheet/anim từ sprite-8dir-anim / anim-video (attack, hit, idle…) + tuỳ chọn tên frame "active".
- Hurtbox: bao alpha thân (bỏ vũ khí/hiệu ứng bằng so sánh với frame idle cùng hướng) → 1–3 hộp/frame.
- Hitbox: vùng pixel mới xuất hiện so với idle ở frame active (vũ khí vung, hiệu ứng) → hộp/đa giác; Claude (Opus) chỉ đoán
  frame active khi người dùng không ghi.
- Sự kiện: `attack_start`, `hit_active`, `recover`, `footstep` (frame chân chạm đất từ đáy alpha).
- Ra: `frame_data.json` + Godot AnimationPlayer track bật/tắt `Area2D/CollisionShape2D` + method track; Unity ScriptableObject
  `FrameData` (script dùng chung GUID cố định) + AnimationEvent trên clip; preview overlay hộp lên sheet.
- Nghiệm thu: 8 hướng × attack có hitbox chỉ ở frame active, hurtbox phủ ≥90% alpha thân; Godot headless chạy scene bật/tắt đúng frame.
- File: ops/frame_data.py, export/frame_data.py, recipes/combat-frame-data.yaml, tests/test_r8_frame_data.py.

### #60 Spine → Unity 2D Animation / Godot Skeleton2D
- Vào: thư mục Spine 4.2 (json + atlas) từ spine-character / spine-face / spine-physics.
- Godot: `Skeleton2D` + `Bone2D` (rest từ setup pose), `Polygon2D` theo attachment (region → quad, mesh → polygon + weights),
  animation rotate/translate/scale/attachment → `Animation` (bezier → nội suy); physics → bỏ, ghi cảnh báo.
- Unity: sprite atlas + `SpriteSkin` / bones qua 2D Animation package (prefab có bone hierarchy + weights), AnimationClip
  từ timeline; thiếu package → chỉ xuất Sprite + Animator dạng cutout, ghi chú.
- Ngoài phạm vi: deform/ path/ IK constraint (ghi cảnh báo, giữ pose đã bake theo frame nếu cần: tuỳ chọn "bake 30fps").
- Nghiệm thu: rig spine-test girl → Godot headless render frame 0 lệch ≤2px so với spine-core render; 1 anim chạy;
  Unity bản copy import 0 lỗi, clip chạy (batchmode chụp 2 frame).
- File: export/spine_skeleton2d.py, export/spine_unity2d.py, recipes/spine-to-engine.yaml, tests/test_r8_spine_convert.py.

### #61 3D LOD chain + collision
- Vào: GLB/FBX (prop-3d, modular-kit, library-import, terrain prop) + preset mobile/PC (tỉ lệ 1 / 0.5 / 0.25 / 0.1 hoặc tam giác đích).
- Blender headless: LOD1..n decimate collapse giữ UV seam + normal; collision: box / convex hull / V-HACD-like nhiều hull
  (dùng convex_hull theo cụm voxel, đã có ở fracture_bpy); bake impostor (billboard 8 góc) cho LOD cuối tuỳ chọn.
- Ra: Unity prefab `LODGroup` + `MeshCollider(convex)`/BoxCollider; Godot `.tscn` `visibility_range_begin/end` + `CollisionShape3D`;
  báo cáo tam giác từng LOD.
- Nghiệm thu: LOD1 ≤55% tam giác, silhouette IoU ≥0.95 ở khoảng cách chuyển; collider bao kín mesh (tỉ lệ thể tích hull/mesh ≤1.4).
- File: adapters/blender/lod.py + lod_bpy.py, ops/lod.py, export/lod.py, recipes/lod-chain.yaml, tests/test_r8_lod.py.
